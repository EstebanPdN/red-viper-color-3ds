# Notices for beta-01

Red Viper Color is a noncommercial modification of Red Viper. The complete
[upstream README](README.md#license) preserves David Tucker's Reality Boy
terms and the credits for Red Viper, r3Ddragon and Red Dragon. The same terms
apply to their respective code here. Individual MIT notices remain in the
upstream files that carry them. The splash art credits Morintari and the
banner audio credits thunderstruck, as in the upstream README.

The independently authored VBCP reader, renderer, and host check carry
[MIT terms](licenses/color-runtime-MIT.txt) in their SPDX-marked files. They
implement file format facts from the public VBoyColor guide, byte layouts
from its public pack tooling, and the standard FNV-1a tile identifier.
The emulator links no VBoyColor code. [Color pack guide and authorship](https://github.com/yuk27/VBoyColor/blob/9a1cd8f93423b00bdc1aa33c364afc6cfd9c314a/docs/COLOR_PACKS.md)

The palette directory in this repository and the standalone SD archive retain
the upstream VBoyColor license and attributions. The CIA and 3DSX contain
the app artwork and a filename template. Palette files are loaded from SD.
